# 🚌 M6405 & M6450 광역급행버스 운행 데이터 자동 수집기

인천 송도국제도시와 서울 강남권을 오가는 **M6405** 및 **M6450** 버스의 **정류장별 소요 시간**과 **실시간 잔여 좌석 수**를 출/퇴근 시간대에 자동으로 기록하고, 세션 종료 시 **텔레그램으로 요약 리포트와 CSV 파일**을 전송하는 자동화 프로그램입니다.

---

## ⏱️ 수집 시간대 및 방향
- **아침 출근 세션 (05:00 ~ 10:00)**: 송도 $\rightarrow$ 서울 (출근 방향)
- **저녁 퇴근 세션 (17:00 ~ 22:00)**: 서울 $\rightarrow$ 송도 (퇴근 방향)
- **수집 주기**: 기본 40초 간격 실시간 위치 및 잔여 좌석 폴링
- **종료 시**: 날짜별 CSV 파일 자동 저장 (`data/YYYY-MM-DD_morning.csv`) 및 텔레그램 알림 발송

---

## 📋 1. 사전 준비 (API 키 & 텔레그램 봇 발급)

### [1단계] 공공데이터포털(data.go.kr) API 키 발급 (약 3분 소요, 즉시 승인)
1. [공공데이터포털 (data.go.kr)](https://www.data.go.kr)에 접속하여 회원가입 및 로그인합니다.
2. 검색창에 아래 **2가지 오픈API**를 각각 검색하여 **[활용신청]** 버튼을 누릅니다 (신청 즉시 자동 승인됩니다).
   - **`인천광역시_버스노선정보조회 서비스`**
   - **`인천광역시_버스위치정보조회 서비스`**
3. 상단 메뉴의 **[마이페이지] $\rightarrow$ [데이터활용] $\rightarrow$ [OpenAPI] $\rightarrow$ [활용신청 현황]**으로 이동합니다.
4. 승인된 서비스 상세 페이지에서 **일반 인증키 (Decoding 키)**를 복사합니다.

---

### [2단계] 텔레그램 봇 생성 및 Chat ID 확인 (약 1분 소요)
1. 텔레그램 앱 검색창에서 `@BotFather`를 검색하여 대화를 시작합니다.
2. `/newbot` 명령어를 전송합니다.
3. 봇 이름(예: `MyBusTracker`)과 봇 아이디(예: `m6405_tracker_bot`, 끝에 `bot`으로 끝나야 함)를 입력합니다.
4. 발급된 **API Token**을 복사합니다. (예: `123456789:ABCdefGhIJKlmNo...`)
5. 생성된 내 봇의 대화방 링크를 눌러 들어가서 **`/start`**를 한 번 전송합니다.
6. 내 **Chat ID(숫자)** 확인:
   - 텔레그램 검색창에 `@userinfobot`을 검색하고 대화를 시작하면 본인의 `Id: 12345678` 숫자가 바로 표시됩니다.

### 2) `.env` 파일 생성 및 설정
`.env.example` 파일을 복사하여 `.env` 파일을 만들고 발급받은 키를 입력합니다:

```bash
cp .env.example .env
```

`.env` 파일 내용:
```ini
DATA_GO_KR_API_KEY=발급받은_공공데이터포털_일반인증키(Decoding)
TELEGRAM_BOT_TOKEN=발급받은_텔레그램_봇_토큰
TELEGRAM_CHAT_ID=본인의_텔레그램_숫자_아이디
COLLECT_INTERVAL_SEC=40
```

## 🚀 4. 프로그램 실행

### 1) 매일 자동 실행 (스케줄러 데몬)
매일 정해진 시간(05:00, 17:00)에 자동으로 켜져서 수집하고 종료 시 텔레그램으로 보냅니다:

```bash
# 지금 시각이 05~08시 또는 17~22시 사이라면 즉시 수집 시작하고 이후 자동 스케줄 유지
python main.py --run-now
```

#### 맥(Mac) 백그라운드 무중단 실행 (터미널을 닫아도 계속 실행):
```bash
nohup python3 main.py --run-now > collector.log 2>&1 &
```
*(종료가 필요할 때는 `pkill -f main.py`)*

### 2) 수동으로 시작 및 종료 (테스트용) ⭐

원하는 시점에 바로 수집을 시작하고, 끝내고 싶을 때 언제든 수동으로 종료할 수 있는 2가지 방법을 제공합니다:

#### 방법 A: 대화형 실행 (엔터 키로 종료)
터미널에서 직접 보면서 테스트할 때 가장 편리한 방법입니다.

```bash
python manual_collector.py
```
1. 방향 선택 (1: 출근 방향, 2: 퇴근 방향, 3: 양방향 전체)
2. 실시간으로 버스 통과/좌석/시간 로그 출력
3. **그만 수집하고 싶을 때 [Enter] 키를 누르면 즉시 종료**되며, 그때까지의 데이터가 CSV로 저장되고 텔레그램으로 자동 발송됩니다!

#### 방법 B: 명령어 기반 시작 / 종료 (`bus_ctl.py`)
백그라운드에서 돌려놓고 나중에 명령어로 종료하고 싶을 때 사용합니다.

```bash
# 1. 수집 시작 (백그라운드 가동)
python bus_ctl.py start

# 2. 현재 수집 상태 확인
python bus_ctl.py status

# 3. 수집 종료 (종료 신호를 보내고 데이터 저장 및 텔레그램 발송)
python bus_ctl.py stop
```
